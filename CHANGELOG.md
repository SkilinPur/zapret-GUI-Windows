# Changelog

Все заметные изменения проекта. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.1.3] — 2026-09-10

### Исправлено
- Краш при первом запуске: системный трей был скопирован из Linux-версии и дёргал несуществующие методы (`tray_start_zapret`). Трей переписан под Windows (показать окно / завершить программу), добавлена защита — если трей недоступен, окно всё равно открывается.

## [0.1.2] — 2026-09-10

### Исправлено
- Пустой архив релиза: PyInstaller собирает одиночный `ZapretGUI.exe`, а упаковка ждала папку. Архив теперь содержит рабочий `.exe` (~49 МБ).

## [0.1.1] — 2026-09-10

### Изменено
- CI: выдано право `contents: write` — релизы с `.exe` теперь создаются автоматически по тегу.

## [0.1.0] — 2026-09-10

### Добавлено
- Каркас Windows-GUI: вкладки «Статус», «Способ обхода» (с авто-описанием), «Обновление» (ядро/стратегии), «Как пользоваться»; тёмная тема, трей.
- Бэкенд на winws + WinDivert: разбор нативных Flowseal-стратегий, запуск/остановка winws, загрузка ядра и стратегий из пакета Flowseal.
- Сборка в `.exe` через GitHub Actions (запуск от администратора).
