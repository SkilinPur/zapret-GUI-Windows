# Changelog

Все заметные изменения проекта. Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [0.1.11] — 2026-09-10

### Исправлено
- Надёжная остановка обхода: теперь убивается всё дерево процессов (taskkill по PID запуска + по имени winws.exe), с ожиданием и предупреждением, если процесс остался (запущен вне программы или как служба). Раньше winws мог «пережить» нажатие «Выключить».

## [0.1.10] — 2026-09-10
## [0.1.10] — 2026-09-10

### Добавлено
- Вкладка **«Telegram»**: модуль **Tg WS Proxy** (локальный MTProto-прокси Flowseal для Telegram Desktop) — скачивание/обновление компонента из релизов tg-ws-proxy, запуск/остановка, статус и secret/порт из конфига, кнопка «Подключить в Telegram» (tg://proxy-ссылка).

> Примечание: антивирусы иногда ложно помечают TgWsProxy.exe из-за упаковщика — при проблемах добавьте файл в исключения.

## [0.1.9] — 2026-09-10
## [0.1.9] — 2026-09-10

### Добавлено
- Вкладка «Статус»: кнопка **«Проверить YouTube/Discord»** (проверяет доступность сайтов, с временем ответа) и **«Очистить кэш Discord»**.

## [0.1.8] — 2026-09-10

### Добавлено
- Вкладка «Способ обхода»: **GameFilter** (выкл/TCP и UDP/TCP/UDP) и **режим охвата ipset** (весь трафик/только списки/по списку IP) — GUI пишет те же флаги/списки, что программа Flowseal (`utils/game_filter.enabled`, `lists/ipset-all.txt` + `.backup`), они подхватываются при запуске.

## [0.1.7] — 2026-09-10

### Исправлено
- Запуск стратегии теперь идёт **через сам `.bat` Flowseal** (winws запускается в фоне, окно скрыто): так корректно подставляются `%BIN%`/`%LISTS%`, создаются user-списки и подставляются GameFilter-порты. Раньше winws запускался без этой подготовки и падал с «windivert filter: must specify port». Вывод по-прежнему пишется в `logs/`.

## [0.1.6] — 2026-09-10

### Изменено
- GUI стал **обёрткой над пакетом Flowseal** (как Linux-версия над портом): скачивается и раскладывается релиз-пакет Flowseal в `engine/` (стратегии `.bat`, `lists/`, `bin/` с winws.exe и WinDivert), ядро и стратегии запускаются/обновляются из него. Обновление = замена пакета на свежий релиз Flowseal.

## [0.1.5] — 2026-09-10

### Исправлено
- Генерация описания релиза из CHANGELOG падала на Windows-консоли из-за кодировки (UnicodeEncodeError) — вывод описания принудительно в UTF-8.

## [0.1.4] — 2026-09-10

### Добавлено
- Подробный лог в вкладке «Статус»: вывод каждого winws сохраняется в `logs/`, и если обход остановился сам — в журнал выводится причина (код выхода процесса и последние строки его лога).

## [0.1.3] — 2026-09-10

### Исправлено
- Краш при первом запуске: системный трей был скопирован из Linux-версии и дёргал несуществующие методы (`tray_start_zapret`). Трей переписан под Windows (показать окно / завершить программу), добавлена защита — если трей недоступен, окно всё равно открывается.

## [0.1.2] — 2026-09-10

### Исправлено
- Пустой архив релиза: PyInstaller собирает одиночный `ZapretGUI.exe`, а упаковка ждала папку. Архив теперь содержит рабочий `.exe` (~49 МБ).

## [0.1.1] — 2026-09-10

### Изменено
- CI: выдано право `contents: write` — релизы с `.exe` теперь создаются автоматически по тегу.

## [0.1.0] — 2026-09-10

### Добавлено
- Каркас Windows-GUI: вкладки «Статус», «Способ обхода» (с авто-описанием), «Обновление» (ядро/стратегии), «Как пользоваться»; тёмная тема, трей.
- Бэкенд на winws + WinDivert: разбор нативных Flowseal-стратегий, запуск/остановка winws, загрузка ядра и стратегий из пакета Flowseal.
- Сборка в `.exe` через GitHub Actions (запуск от администратора).
